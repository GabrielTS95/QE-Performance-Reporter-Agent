# Evidencias complementarias

Coloca aqui las evidencias opcionales que ayuden a enriquecer el analisis de performance.

Ejemplos utiles:

- Imagenes de monitoreo de CPU, memoria, red, base de datos o contenedores.
- Capturas de dashboards de APM, observabilidad o logs.
- Graficas de errores, latencia, throughput o saturacion.
- Logs o reportes complementarios relacionados con la ventana de la prueba.

Usa nombres descriptivos que incluyan fecha, hora o componente cuando sea posible, por ejemplo:

```text
monitoring-api-pagos-2026-09-19-1030.png
logs-timeouts-api-pagos.txt
apm-latencia-checkout-pico.html
```
